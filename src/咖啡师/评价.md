# 评价
**缺点**

| 序号  | 内容             | 说明                                                                                                                                                                                                                                                                                                                   |
| --- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 克扣工时           | 比如排班：13：30 ~ 22：30， 中间有两次休息共1个半小时，但实际只休息不到半小时。多的时间都是打白工。                                                                                                                                                                                                                                                             |
| 2.  | 学习成本           | 每周都会上新品然后经常性的运营事物调整（制作标准、清洁标准。。。）这些东西都要记住，但是花的都是自己的时间，上班时就只有干活。尤其是前期：入职的准备、培训、配方记忆、门店熟悉。。。                                                                                                                                                                                                                           |
| 3   | 标准严格           | 每半小时换一次红色抹布；双数整点洗一次手；每隔3小时换一次消毒水。。。基本上没有多余休息时间，相比工厂流水线，可以看作是“活动的流水线“<br>要求严格执行，但标准本身漏洞百出。                                                                                                                                                                                                                            |
| 4   | 个人发展空间有限       | 两种晋升路线，大部分咖啡师-》值班-》副店长（全职）-》店长，这就到头了                                                                                                                                                                                                                                                                                 |
| 5   | 排班             | 一个店只有店长、副店长是全职，他们随时准备上班，其他人都是兼职。如果控制工时，那么排班可能比较混乱，会根据当前实时单量让你提前上班或推迟下班。原本是下午3点上班，正常两点多准备上班。因为可能出现提前的情况，要在1点多就准备好。这样实际是侵占了个人休息时间，人虽然没到店里，但是心已经到了。                                                                                                                                                                     |
| 6   | 规则制定虎头蛇尾       | 1. 因为发现有员工手有伤口未处理、未佩戴手套，要求必须佩戴胶皮手套。现在不是必须<br>2. 预置物料报损。首先这个功能感觉就不完善，现在茶汤到期直接废弃，奶盖闭店时也是直接倒掉，没有报损过。                                                                                                                                                                                                                    |
| 7   | 入职流程繁琐         | 需要办理健康证，以及完成入职前的线上培训，个人购买工服                                                                                                                                                                                                                                                                                          |
| 8   | 自相矛盾，前后不一，表面工夫 | 搅拌壶的周清-使用牛奶系统清洁液浸泡 必须在闭店之后做，但是奶缸除垢-同样使用牛奶系统清洁液浸泡就可以在营业中进行。<br>接触化学品佩戴手套或洗手：前一秒戴着手套倒完了多功能清洁液，后一秒脱下手套就可以在满是清洁液清洗池里清洗器具了                                                                                                                                                                                                |
| 9   | 没有报号系统         | 虽然点单后手机上可以看到 预计取餐时间、是否制作完成，但是很多人不（会）看。尤其是高峰的时候，一堆人挤在出餐口问 “做到多少号了”，“xxx好了没”，“还要多久” 这些问题都算正常，尤其受不了的是回答“现在在做123”然后被问“136好了吗” “没好，在做123” 边上的人再问“148好了吗”。。。真的无语，有的时候不得不怀疑是否接受过小学教育。这些问题其实都可以解决掉，加装一个报号的屏幕就行了，可以是小一点的屏幕嘛，就显示一个当前取餐号，下一取餐号。要不加一个喇叭，播放声音也行。就为了节省一点成本，把这点成本转移、平摊到员工身上。让员工进行不必要的、重复性的、机械性的回答，同时容易引起员工和顾客之间的反感。 |
| 10  | 内卷竞争           | 即使标准要求可以减少的工作内容，实际执行也不会有所减少。甚至因为品控或指标 增加比标准更严格的、更复杂的工作内容。                                                                                                                                                                                                                                                            |

**其他**
- 只能根据完整的手机号码搜索订单（不能查询尾号且没有任何提示）
- 点击取餐，不能选择区间或一次性全部完成，只能一个一个点
	- 不点完取餐就没办法解冻
- 咖啡机的豆仓
	- 装卸费力：底部的封口片安装是有正反的。可能是安装错误，然后强行固定，导致锁止拉杆不能很好地移动，解除锁定的时候封口片卡住，出不来。每次取豆仓的时候都十分费力。
	- 豆仓能不能设计为倾斜的？进豆口在前面，用着用着口子附近就空了，但是后面的豆子不会自己往前面落，要手动把后面的豆子扒到前面。
- 咖啡液首杯测重：营业后首杯标准美式会要求测试咖啡液重量。此项作为专项检查，视频看到没有测试会扣分。关键是如果没有看到提示测重量的提醒，已经接取了咖啡液，似乎没有办法补救。这里不能增加一个确认选项吗？提醒测试-》确认测试完成-》完成订单；提醒测试-》完成订单 表示没有进行测试-》下一杯再次提醒-》确认测试完成 
- 茶汤效期报备：单屏机提示茶汤即将过期，需要拍摄照片发到群里
- 除牛奶、椰浆外，其他物料使用死效期。禁止提前多次打印效期
规定前使用活效期的物料：苏打水、酸奶。
使用死效期也没什么问题，但是不让提前打效期，那么高峰期的时候一瓶酸奶做不了一杯饮品，中途打效期多费力啊！
- 特调限时供应：从早上开始营业到晚上闭店售卖的东西叫做限时供应？😅
- 标准不一：虽然有一个瑞幸大学规定了一些标准，但到了实际执行时往往采用不一样的步骤、方法。特别是标准不可能面面俱到，事无巨细，只能起到一个指导性的说明。很多事情上都没有规范，对标准理解的差异导致不同地区甚至是同一个区域不同的店长在同一件事情上的要求都不一样。
	- 接触除垢粉要不要佩戴一次性手套 或 洗手
关于三联池除垢：
	- 配置以及喷洒除垢液是否佩戴手套
		店长：除了消毒片接触其余化学品均要戴一次性手套，配置以及喷洒过程中均需佩戴手套
		副店长：不需要带手套
	- 喷洒除垢液后是否需要静置
		店长：静置5分钟
		副店长：不需要，直接使用绿色百洁布擦拭
	- 消毒抹布盒子的清洁
		店长：清水冲洗
		副店长：用蓝色毛巾擦拭
- 废水桶的使用
储冰车下面有个废水桶，主要用处：
1. 接取储冰车内部融化后的冰水
2. 冲隔渣池
3. 打烊后接取热水融化储冰车内剩余冰块
4. 接取拖地用热水

重点是第四个，在没洗手的情况下（按照瑞幸的标准，没洗手就应该算作是赃物的），刚打卡上班，或吃饭回来，准备拖地，可以直接接触废水桶。但是不能接触其它器具、材料 - 开水机开关。洗完手的情况下也可以直接接触废水桶。这是不是存在交叉污染的情况？
- 心累：原以为上个兼职的班，只要无脑做做单就可以了，没有什么心里负担。体验下来，并不比和办公室里的人相处“轻松”。我承认没有将这份工作放在心里，因为这份工作本身就不是我的目标，这里投入越多，能够花在其它事情的精力就越少，损失也就越大。但是该做的步骤没有省略。人与人的能力差异很大，过程慢也没办法，真的没有情绪能带动我让我快一点。比别人扫码可能要慢上5分钟左右。因为弄得慢可能影响开早，所以早了5分钟到。  排班：6：30~16：00，早上没什么单，所以想着帮晚班的伙伴减轻负担把周清-三联池、豆仓做了。做了第一台咖啡机的豆仓，本来是要做三联池的，但是看到除垢粉的包装好像换了，包装说明上写着一包粉2L水（没仔细看）不确定是不是，但是也快到第二个人来上班了就想着等下问了之后再做。排了一个小时休息，中间上了个厕所，买了杯燕麦粥喝，有没有十分钟？然后就继续干活了。后面一直来单，睡眠不足+做单+长时间站立+没有休息-》腿疼、肚子饿 想上厕所，憋着尿，犹豫了下，还是没有提出要去厕所。整理完货物之后已经是16：30左右了，但是三联池还没弄。被问为什么上午没多少单的情况下怎么不把三联池弄了？做了什么，我回答豆仓，“豆仓让咖啡师晚上弄，10点把三联池洗了” 打出这段文字，我笑了。即使没单我也没休息啊，3个奶盖，抹茶，茶汤，豆仓，咖啡豆份数盒，营业中任务，作业上传。。。 这些任务没有什么问题吧？最最重要的是，我现在不是加班在做三联池吗 当然了，往好的看是在提醒我事情的处理顺序（优先级），但是在我劳累了一天（9.5h）的情况下听到的不是肯定而是疑问的时候，感觉好没意思，心里想的是：算了吧。原本下班的喜悦也被这股情绪冲刷得一干二净。
