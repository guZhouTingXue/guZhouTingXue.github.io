# 7.3 Voice
>[!info]
>语态是谓语动词的一种形式，用来表示句子的主语 和 谓语动词所表达的动作之间的关系。

| 类型                | 主语的作用        |
| ----------------- | ------------ |
| The Active Voice  | 动作的发出者 或 执行者 |
| The Passive Voice | 动作的承受者       |

- [Using the Passive Voice](Resources/Using%20the%20Passive%20Voice.md)


## 被动语态的类型 312
>一般说来，英语及物动词的主动语态可以转换为被动语态。

以下标题为及物动词的主动语态构成形式。
具有相同含义的主动、被动例句放在有序列表内。单独的被动语态例句放在无需列表中。
颜色标记：主谓宾使用固定颜色-红黄蓝标记，其余句子成分视具体情况而定，可能相同，也可能不同。

### 1. subj. + vt. + obj.
- Today all kinds of measures are taken to prevent pollution.
- You are wanted on the phone.

转换后 obj. 不见了

### 2. subj. + vt. + obj. + obj.complement
1. We heard the song sung everyday.
The song was heard sung everyday.

2. <span style="background:#ff4d4f">We</span> <span style="background:#fff88f">heard</span> <span style="background:#40a9ff">him</span> <span style="background:#affad1">say good-bye to his friends</span>.
He was heard to say good-bye to his friends.

active voice 中 say good-bye，say 是bare infinitive
转换后obj. complement => subj. complement
say => to say

**let**
后跟动词 drop, fall, fly, go, slip ...

## 被动语态的各种时态构成形式 328

| tense               | passive voice             | active voice             |
| ------------------- | ------------------------- | ------------------------ |
| simple present      | is/are done               | simple present verb - do |
| simple past         | was/were done             | simple past verb - did   |
| simple future       | will/shall be done        | will do / be going to do |
|                     |                           |                          |
| present progressive | is/are being done         | am/is/are doing          |
| past progressive    | was/were being done       | was/were doing           |
| present perfect     | has/have been done        | has/have done            |
|                     |                           |                          |
| past perfect        | had been done             | had done                 |
| future perfect      | shall/will have been done | will have done           |

一般过去将来：should/would be done
过去将来完成：should/would have been done

- perfect progressive 不用于passive，因为其表示的是 duration 
- 由于done是固定的，be 来表示动作的状态
