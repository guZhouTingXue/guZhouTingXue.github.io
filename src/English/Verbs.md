# 7. 动词 Verbs
>[!info]
>表示动作 或 状态。在句中 主要做谓语，有人称、数、时态、语态 和 语气的变化。不同时态 和 语态的动词组成的动词短语，还可做定语、状语、主语 和 宾语

## 分类
### 句法

| 序号  | 类型             | 示例  | 中文名称 |
| --- | -------------- | --- | ---- |
| 1   | Notional Verb  |     | 实义动词 |
| 2   | Link Verb      |     | 系动词  |
| 3   | Auxiliary Verb |     | 助动词  |
| 4   | Modal Verb     |     | 情态动词 |

### 语法结构
- 是否在句中作谓语-》受到主语的限定，有人称、数、时态、语态 和 语气的变化：限定动词 - Finite Verb
- 不能独立作谓语，必须与一定的助动词结合，一起构成复合谓语 或 充当其他句子成分-》不会受到主语（人称、数）的限制：非限定动词 - Non-finite Verb

#### Finite Verb
在表示语法概念中的限定时，finite的反义词是Non-finite。其他情况finite - 有限的反义词是 infinite - 无限的。

| Character is the first and last word in success circle. | is         | is    | 第三人称 + 一般现在时 |

## 系动词
### 始动性 Inchoative
状态的变化 或 发展 或 变化/发展的结果
1. 状态变化：become, go, grow, run
2. 结果：come, drop, fall, get, make, prove, turn, wear
3. 颜色/脸色变化: blush, burn(只能是颜色), flame, flash, flush

### 延续性 Continuative

| 时态   | 现在           |          | 过去            |           |
| ---- | ------------ | -------- | ------------- | --------- |
| 数    | 单            | 复数       | 单             | 复数        |
| 第一人称 | I am         | we are   | I was         | we were   |
| 第二人称 | you are      | you are  | you were      | you were  |
| 第三人称 | he/she/it is | they are | he/she/it was | they were |
1. 当前状态：be、lie
2. 保持状态：continue, keep, remain, rest, stand, stay

### 感觉性 Sense
**人** 对外界事物 **特征** 或 **状态** 的感受
 appear, seem, look;feel;ring, sound; smell; eat, taste
